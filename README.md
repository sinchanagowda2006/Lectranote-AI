# 🧠 LectraNote AI

LectraNote AI is an AI-powered study assistant that helps students learn from YouTube lectures.

## ✨ Features

- 📺 Download YouTube lecture audio
- 📝 Generate AI-powered study notes
- 🎯 Interactive quiz generation
- 🃏 AI flashcards
- 💬 AI Tutor (Q&A)
- 📄 Export notes as PDF

## 🛠️ Tech Stack

- Streamlit
- Groq API (Llama 3.3 70B)
- OpenAI Whisper
- yt-dlp
- ReportLab

## 🚀 How to Run

1. Install dependencies

```bash
pip install -r requirements.txt
```

2. Set your Groq API key as an environment variable.

3. Run the app

```bash
streamlit run appv2.py
```
